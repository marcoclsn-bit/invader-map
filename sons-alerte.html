Le son d'alerte — version longue

L'arcade passe de 0,51 s à 1,02 s. Les deux versions sont là pour comparer, ainsi que les deux autres candidats. Monte un peu le volume.

C'est la version longue qui est dans le dépôt. Le fichier doit être dans le binaire — le plugin le recopie à la construction, un son ne peut pas arriver par la suite. En revanche, CHOISIR lequel se joue est une ligne de JavaScript : SON_ALERTE dans strollEngine.js. Ce changement-là part par-dessus les airs, sans revue Apple. Tu peux donc décider après coup, et même changer d'avis.
