# InvaderQuest

Application mobile pour repérer les mosaïques Space Invader : carte, chasse au
trésor sur un temps donné, itinéraires et lieux d'intérêt.

Disponible sur l'App Store et Google Play. Projet indépendant, sans lien ni
affiliation avec l'artiste Invader.

## ⚠️ Ce dépôt n'est pas open source

Il est public **uniquement pour héberger les données que l'application
télécharge** (mises à jour des Invaders, lieux d'intérêt, traductions) et pour la
transparence sur le traitement des données.

**Le code source, les traductions d'interface et les éléments graphiques sont
